# Semaine 8 - Jour 2 - Héritage et encapsulation

**Auteur :** [Alain] [YEMMING]

## Définitions

**Héritage :** L'héritage permet à une classe (la classe fille) de reprendre les attributs et les méthodes d'une autre classe (la classe mère), et d'y ajouter ou de modifier des comportements.

**Encapsulation :** L'encapsulation consiste à protéger les données d'une classe (attributs privés) et à n'y donner accès que par des méthodes contrôlées.
